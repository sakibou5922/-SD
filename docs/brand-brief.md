## 1. ブランド戦略

### 1.1 事業の前提
株式会社SDは **Web制作事業のみ** を行う小規模なスタジオです。クライアントのWebサイトの企画・設計・デザイン・実装・公開後の運用までを、少人数で一貫して手がけます。本ブリーフはこの一事業に限定し、他の事業や商品を想定しません。

### 1.2 Purpose（存在理由）
**「つくりの良いWebを、当たり前にする。」**
見た目だけでも、機能だけでもない。構造・動き・コードが一体になった "つくりの良さ" を、規模の大小にかかわらずクライアントに届けるために存在する。

### 1.3 Vision（目指す姿）
**「構造・動き・コードをひとつのデザインとして扱う、最も信頼される小さなスタジオ。」**
大きくなることではなく、一件ごとの精度と説明可能性で選ばれ続けること。

### 1.4 Mission（果たすこと）
**「事業の目的を、正しく動くWebの構造に翻訳する。」**
クライアントの目的をヒアリングし、情報設計・ビジュアル・実装・運用を分断せずに設計する。公開後も数字と対話をもとに改善を続ける。

### 1.5 Values（価値観）
| # | 価値 | 意味 | ふるまい |
|---|---|---|---|
| 1 | **構造から考える** | 装飾より先に、情報の骨格と動線を決める | ワイヤー・設計図・仕様をクライアントと共有してから描き始める |
| 2 | **動きに意味を持たせる** | モーションは演出ではなく、理解を助ける説明である | すべてのアニメーションに「何を伝えるためか」を書けること |
| 3 | **コードまで責任を持つ** | 設計とデザインは、実装の品質で完成する | 表示速度・アクセシビリティ・保守性を成果物の一部として納品する |
| 4 | **静かに、誠実に** | 誇張せず、できることとできないことを明確にする | 見積・工程・リスクを先に伝える。小さな会社である事実を隠さない |

### 1.6 ブランドパーソナリティ
- **精密（Precise）** — 言葉も線も、迷いなく置かれている
- **静穏（Calm）** — 騒がず、急がず、確かに動く
- **職人的（Crafted）** — 手の跡が見える。工程を語れる
- **誠実（Honest）** — 小さな会社であることを含め、事実で語る

### 1.7 ポジショニング
- **ターゲット**: 自社サイト・サービスサイト・ブランドサイトを "ちゃんと" つくりたい中小企業、スタートアップ、個人事業主、およびデザイン品質に敏感な事業部門。
- **差別化**: 「構造・動き・コード」を分業せず一体で設計すること。大規模代理店の総合力ではなく、少人数だからこそ可能な一貫性と密度で勝負する。
- **ポジショニング・ステートメント**:
  > 株式会社SDは、構造・動き・コードをひとつのデザインとして扱う小さなWeb制作スタジオです。設計から実装、公開後の改善までを同じ手で行うことで、見た目と機能が分離しない、長く使えるWebをつくります。
- **ブランド・プロミス**: 「なぜそうなっているか」を、すべて説明できるWebを納品する。

## 2. タグライン

### プライマリ（採用）
**構造が、動き出す。**（8文字）
- 意味: 情報設計（構造）が、モーションと実装によって "生きて動く" 体験になる。3Dスクロール演出とも直結する。
- 英語サブコピー: **Structure in motion.**

### 代替案
1. **設計を、動かす。**（7文字） — より主体的。プロセス訴求が強い場合に。
2. **静かに、精密に。**（7文字） — パーソナリティ寄り。抽象度が高いが記憶に残る。

### 使用ルール
- 句読点「、」「。」を含めて一体のロゴタイプ的表現として扱う。改行は「、」の後のみ許可。
- 英語サブコピーは常にタグラインの下または右に、小さく添える（同格に並べない）。

```css
  --sd-surface-2:     #1B2230;  /* ホバー時・入力欄 */

  --sd-text-2:        #9AA3B2;  /* 補足・キャプション・ナビ非アクティブ */

  --sd-secondary:     #D4A65A;  /* セカンダリアクセント: 真鍮色。番号・ラベル・強調の対比 */
  --sd-signal:        #FF6B4A;  /* シグナル: CTAボタン背景のみ。他用途禁止 */
  --sd-signal-text:   #0B0E14;  /* CTAボタン上の文字色 */

  /* 3D Scene */
  --sd-3d-clear:      #070910;  /* renderer.setClearColor */

  --sd-3d-emissive-b: #D4A65A;  /* 副発光: 節点・強調ライン（全体の10%以下） */
  --sd-3d-material:   #2A3446;  /* 非発光メッシュのベース（金属・マット面） */
  --sd-3d-fog:        #0B0E14;  /* フォグ色は背景と一致させる */
}
```

**コントラスト（対 `--sd-bg` #0B0E14、WCAG 2.x 相対輝度による概算）**
| 前景 | 比率 | 判定 |
|---|---|---|
| `--sd-text` #F2F4F7 | 約 17.5 : 1 | AAA |
| `--sd-text-2` #9AA3B2 | 約 7.6 : 1 | AAA（本文可） |
| `--sd-text-3` #6B7484 | 約 3.8 : 1 | 18px以上/太字の大きな文字のみ AA。本文不可 |
| `--sd-primary` #5EE1C5 | 約 12.0 : 1 | AAA（リンク・見出し可） |
| `--sd-secondary` #D4A65A | 約 8.7 : 1 | AAA（ラベル可） |
| `--sd-signal-text` on `--sd-signal` | 約 6.9 : 1 | AA（ボタン文字） |
| `--sd-text-2` on `--sd-surface` | 約 7.0 : 1 | AAA |

**運用ルール**
- 発光色（primary / secondary）は画面全体の面積の **5%以下**。背景の暗さが主役。
- `--sd-signal` はCTAボタン専用。テキストリンクや装飾に使わない（CTAの一意性を守る）。
- グラデーションは `--sd-primary` → 透明のみ許可。primary→secondary の直接グラデーションは禁止（濁る）。

### 3.3 ロゴ（ワードマーク）仕様
ロゴファイルは存在しないため、テキストによるワードマークを正とする。

- **文字**: `SD`（大文字2文字）。Inter Tight 600。
- **字間**: `letter-spacing: -0.02em`（2文字を密に）。S と D の間に光学調整の余白を入れない。
- **サイズ**: ナビでは 22px（`1.375rem`）。最小 16px。
- **色**: `--sd-text`。ホバー時のみ `--sd-primary`。
- **区切りマーク**: ワードマークの右に **幅 6px・高さ 6px の正方形** を `--sd-primary` で置き、ベースラインに揃える（`SD ■`）。これがブランドの唯一のシンボル要素。3Dシーンの「節点」と同じ意味を持つ。
- **フルネーム表記**: フッター・会社概要では「株式会社SD」と `SD Inc.` を併記。ナビには社名を出さない。
- **クリアスペース**: ワードマークの高さ（cap height）の 0.5倍 を四方に確保。
- **配置**: ナビ左端に固定。スクロール中も常に表示（`position: fixed`）。ヒーロー中央には置かない（タグラインが主役）。

```css
.sd-wordmark {
  font-family: var(--sd-font-latin);
  font-weight: 600;
  font-size: 1.375rem;
  letter-spacing: -0.02em;
  color: var(--sd-text);
  display: inline-flex; align-items: baseline; gap: 0.35em;
}
.sd-wordmark::after {
  content: ""; width: 6px; height: 6px;
  background: var(--sd-primary);
}
```

### 3.4 モーション原則
1. **スクロール ＝ 物語。** ページは「構造 → 動き → 実装 → 運用」の一本の筋。3Dシーンの変化は各セクションの意味に対応させ、飾りとして動かさない。
2. **加速しない、減速する。** 基本イージングは `power2.out` / `cubic-bezier(0.22, 1, 0.36, 1)`。バウンス・エラスティックは禁止。
3. **時間は短く、間は長く。** UIトランジションは 200〜400ms、セクション遷移は 600〜900ms。動きの後に必ず静止時間を置く。
4. **一度に動くものはひとつ。** 3Dのカメラ・オブジェクト・テキストが同時に大きく動かない。主役をひとつ決め、他は遅れて小さく従う（stagger 40〜80ms）。
5. **抑制が品質。** `prefers-reduced-motion` ではスクロール連動を停止し、フェードのみ。3Dは静止した最終フレームを表示する。

### 3.5 Do's & Don'ts

**Do**
1. 背景を暗いまま保ち、発光色を「点と線」に限定する
2. 見出し・番号・ラベルの3階層でリズムをつくる（Zen Kaku / Inter Tight / Plex Mono）
3. すべてのモーションに「伝える理由」を添える（設計メモに一行書く）
4. 会社規模・工程・費用感を事実として率直に書く
5. 60fps を維持できない演出は削る（品質は速度に含まれる）

**Don't**
1. 純黒 `#000` や真っ白 `#FFF` の面を使わない
2. `--sd-signal`（コーラル）をCTA以外に使わない
3. 「業界No.1」「圧倒的」「最先端」などの誇張語を使わない
4. 3Dシーンで製品や人物・現実の物体を模さない（抽象的な幾何・粒子・線のみ）
5. 情報のためのテキストを3D内に埋め込まない（テキストは常にHTMLで）

## 4. ブランドボイス＆トーン

### 4.1 ボイス属性
- **簡潔** — 一文一義。40字を超えたら分ける。
- **具体的** — 「良い」「美しい」の前に「何が」を書く。
- **静か** — 感嘆符を使わない。強調は語の選択と改行で行う。
- **対等** — 上から教えない、へりくだりすぎない。相談相手の距離感。

### 4.2 文体
- **見出し・タグライン**: 常体／体言止め（例「構造が、動き出す。」「設計から、運用まで。」）。短く、断定する。
- **本文・説明文**: 敬体（です・ます）。
- **理由**: 小規模なスタジオが法人顧客に語りかける場面では、敬体が信頼と礼節を担保する。一方で見出しまで敬体にすると緊張感が失われるため、見出しのみ常体で "精密さ" を出す。この使い分け自体がブランドの「静穏で精密」なパーソナリティの表現である。

### 4.3 トーンの幅
| 場面 | トーン | 例 |
|---|---|---|
| ヒーロー・見出し | 断定・最小限 | 「構造が、動き出す。」 |
| サービス・工程説明 | 説明的・具体的 | 「公開後は、アクセス解析と対話をもとに改善を続けます。」 |
| お問い合わせ | 開かれた・低い敷居 | 「まだ要件が固まっていなくても、ご相談ください。」 |
| 会社概要・フッター | 事務的・正確 | 表形式、装飾なし |

### 4.4 使う言葉／避ける言葉
**使う**: 構造、設計、動き、実装、運用、精度、工程、説明できる、長く使える、一貫して、ひとつのデザイン
**避ける**: 圧倒的、最先端、No.1、革新的、ワンストップ（※意味は近いが常套句のため「一貫して」を使う）、ソリューション、DX（事業範囲外の含みを避ける）、感嘆符「！」、絵文字

## 6. 3Dチームへの申し送り

1. **世界観は「暗室の中の設計図」。** 背景は `#070910`〜`#0B0E14`。光源は画面内に置かず、オブジェクト自身の発光（emissive）と弱い環境光のみ。フォグ色は背景と一致させ、奥が溶けるようにする。
2. **素材は2種類だけ。** ①非発光のマット／半金属面（`#2A3446`、roughness 0.6〜0.8、metalness 0.2〜0.4）と、②発光するエッジ・粒子・線（主 `#5EE1C5`、副 `#D4A65A`）。副発光は全体の10%以下、「節点」や「決定点」にだけ使う。
3. **形は「構造」を思わせる幾何。** ワイヤーフレームの立方体・格子・面と線のつながり・点群。有機的なブロブや流体、現実の物体・製品・人物の模倣は禁止。ワードマークの `■` と同じ正方形の節点をモチーフとして繰り返してよい。
4. **密度は "疎"。** 粒子は数千〜1万点程度を上限に、画面の大部分は暗いまま残す。密度が上がるのはセクション遷移の一瞬だけ。
5. **速度は遅く、減速で止まる。** カメラや形状の変化は ScrollTrigger の `scrub: 0.8〜1.2` で慣性を持たせ、停止時は `power2.out`。回転は 1 スクロール（100vh）あたり 15°以内。
6. **スクロールの物語を形で語る。** Hero: 散らばった点群 → About: 線でつながり構造になる → Service: 面が生まれ立体になる → Process: 5つの節点が順に灯る → Works: 立体が静止し、ブロック（カード）に分かれる → Contact: 構造が静かに一点へ収束し、`■` になる。
7. **テキストはHTMLに。** 3D内に文字を描かない。ヒーローのタグラインは DOM に置き、3D はその背後で動く。テキストの可読性のため、3D の輝度は文字の背後で `--sd-bg` に対し十分暗く保つ（テキスト領域のオーバーレイ可）。
8. **パフォーマンスとフォールバック。** 目標 60fps（モバイル 30fps 以上）。`prefers-reduced-motion` では最終フレームの静止画を表示。WebGL 非対応時は `--sd-bg-deep` のグラデーション背景のみ。DPR は 2 を上限にクランプ。
